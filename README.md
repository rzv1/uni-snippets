# uni-snippets 

A curated collection of university computer science coursework, laboratory exercises, and algorithmic implementations across various domains and programming paradigms.

---

##  Repository Structure

| Module | Description | Key Topics / Tech |
| :--- | :--- | :--- |
| [`assembly/`](./assembly) | Low-level architecture and assembly programming | x86 / x86_64 Assembly |
| [`c-networking/`](./c-networking) | Socket programming, client-server models, and network data processing | C, Sockets, POSIX |
| [`data-structures/`](./data-structures) | Data structures built from scratch (BST, Hash Table, Linked Lists, Dynamic Vector) | C++ |
| [`declarative-programming/`](./declarative-programming) | Logic and functional programming exercises | Prolog, Lisp |
| [`dynamic-systems/`](./dynamic-systems) | Mathematical modeling worksheets for dynamic systems | Maple (`.mw`) |
| [`graph-theory/`](./graph-theory) | Graph algorithms (BFS, Shortest Paths, Eulerian Paths, Max Flow, Graph Coloring) | C++ |
| [`operating-systems/`](./operating-systems) | System programming, shell scripting, process management, and IPC | C, Bash, AWK |
| [`prob-and-stats/`](./prob-and-stats) | Notebooks covering probability theory, distributions, and Monte Carlo simulations | Python, Jupyter |
| [`sql-server/`](./sql-server) | Database schemas, T-SQL analytical queries, procedures, and versioning | T-SQL, SQL Server |
